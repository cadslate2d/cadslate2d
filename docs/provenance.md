## Dependencies

- **Rust:** `cargo deny check` (in `make check`, configured by [`deny.toml`](../deny.toml)) allows MIT, Apache-2.0, BSD, ISC, Zlib, and Unicode-3.0, and refuses anything else and any crate with a known advisory. Today the dependencies are MIT, Apache-2.0, and Unicode-3.0.
- **JavaScript:** `scripts/check-licenses.sh` (in `make check`) checks the web app's production dependencies, today React, React DOM, and its scheduler, all MIT. Dev dependencies are tooling and are not shipped.
- **Notices:** `scripts/third-party-notices.sh` writes `web/public/third-party-notices.txt`, shipped with the build and linked from Help › About: every Rust and JavaScript dependency the bundle contains, with its licence text, and the Hershey acknowledgements. The check fails when the file is out of date.
