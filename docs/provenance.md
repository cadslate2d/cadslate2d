## Dependencies

- **Rust:** `cargo deny check` (in `make check`, configured by [`deny.toml`](../deny.toml)) allows MIT, Apache-2.0, BSD, ISC, Zlib, and Unicode-3.0, and refuses anything else and any crate with a known advisory. Today the shipped dependencies are MIT, Apache-2.0, and Unicode-3.0. MPL-2.0 is allowed for one dev-dependency, acadrust, the test oracle of `cad-dwg` (ADR-0036); it is never built into the application.
- **JavaScript:** `scripts/check-licenses.sh` (in `make check`) checks the web app's production dependencies: React, React DOM, and its scheduler, all MIT; and pdf.js (`pdfjs-dist`, Apache-2.0, #528), a chunk of its own with its worker, fetched only when a PDF is chosen to attach. Its optional Node canvas is never installed (`web/pnpm-workspace.yaml`). Dev dependencies are tooling and are not shipped.
- **pdf.js's decoders:** the build copies three of the package's WebAssembly decoders beside the page as `pdfjs/` (`web/vite.config.ts`), which pdf.js fetches only for a PDF that needs one: `jbig2.wasm` (PDFium's JBIG2 decoder, BSD-3-Clause), `openjpeg.wasm` (OpenJPEG, BSD-2-Clause), and `qcms_bg.wasm` (qcms, MIT), each as built by the pdf.js project under its library's terms. Their licences are in the notices. The package's other files — its JavaScript sandbox, its fonts and character maps — are not shipped.
- **Notices:** `scripts/third-party-notices.sh` writes `web/public/third-party-notices.txt`, shipped with the build and linked from Help › About: every Rust and JavaScript dependency the bundle contains, with its licence text, and the Hershey acknowledgements. The check fails when the file is out of date.
