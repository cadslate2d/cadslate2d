# Polyline offset corpus (DESIGN §21.3, §22; ADR-0011).
#
# The hard cases of offsetting: corners, segments that disappear, shapes
# that fall apart, arcs that collapse. One case per line:
#
#   <name> : open|closed : <vertex> <vertex> ... : <distance> => <paths> <total length>
#
# A vertex is x,y or x,y,bulge — the bulge of the segment that starts there
# (tan of a quarter of the included angle, positive counter-clockwise).
# The distance is signed: positive to the left of the direction of travel,
# negative to the right. For a counter-clockwise closed shape, left is in.
#
# The runner checks the number of paths and their total length, and — for
# every case — that each point of the result is the offset distance from
# the source. Lengths marked (exact) follow from the geometry; the others
# were recorded from the implementation after that property held.
#
# Blank lines and lines starting with # are ignored. Every fixed bug adds a line.
