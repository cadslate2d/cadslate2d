# Lengthen regression corpus (DESIGN §21.3; #201).
#
#   <object> @ <pick x y> by <delta> => <object>
#   <object> @ <pick x y> by <delta> => nothing     the object would vanish, or an arc reach its full circle
#
# Objects are written as in intersections.txt, or as a polyline:
# `polyline open x,y[,bulge] x,y[,bulge] …`. The end of the object nearer
# the pick is moved `delta` along the object's own line or circle — back,
# for a negative delta.
#
# The runner also checks, for every case, that the other end has not
# moved, that the length changed by the delta, and that the old end is on
# the result (or the new end on the old object, when it got shorter).
